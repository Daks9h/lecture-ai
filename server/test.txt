Welcome everyone to CS 152: Computer Architecture and Engineering. Today we are diving into high-speed arithmetic hardware, specifically focusing on Booth's Multiplication Algorithm, bit-pair recoding, and the IEEE 754 floating-point standard.

When designing an Arithmetic Logic Unit (ALU), naive binary multiplication performs repeated shift-and-add operations. If a multiplier contains long contiguous strings of binary ones, such as 01111110, naive hardware must execute an addition for every single one. This dramatically inflates clock cycle counts and causes datapath bottlenecks. Booth's algorithm solves this bottleneck through the algebraic observation that a string of ones of length k starting at power 2^i can be rewritten as 2^(i+k) minus 2^i. Therefore, instead of performing k sequential additions, the hardware only needs to perform a single subtraction at the start of the string and a single addition at the end.

To implement Booth's algorithm in hardware, the control unit examines two adjacent multiplier bits simultaneously: the current bit Qi and the previous bit Qi-1. At the initialization stage, Qi-1 is always implicitly set to zero. If the pair evaluates to 00 or 11, the multiplier is in the middle of a run of zeros or ones, and no arithmetic operation is necessary—only an arithmetic right shift is performed. If the pair evaluates to 01, this indicates the end of a run of ones, so the multiplicand is added to the accumulator before shifting. Conversely, if the pair evaluates to 10, it indicates the start of a run of ones, so the multiplicand is subtracted from the accumulator before shifting.

Because intermediate partial products can be negative numbers in two's complement representation, the shift operation must always be an Arithmetic Shift Right (SRA), which replicates the sign bit into the most significant position. Using a Logical Shift Right (SRL) would insert zeros into the MSB, corrupting negative values into massive positive numbers.

In modern microprocessors, we extend this technique to Radix-4 bit-pair recoding. In Radix-4, the hardware inspects three overlapping bits at a time (Q2i+1, Q2i, Q2i-1) and processes two multiplier bits per clock cycle, effectively cutting the total number of partial products in half. The recoding values can be -2M, -M, 0, +M, or +2M. The multiple +2M is simple to generate in hardware via a one-bit left shift of the multiplicand.

Finally, we address floating-point arithmetic under the IEEE 754 standard. During floating-point addition and subtraction, significands must be aligned by shifting the smaller operand to the right. To prevent loss of precision and floating-point drift, IEEE 754 requires three extra bits beyond the mantissa: Guard (G), Round (R), and Sticky (S). The Guard and Round bits preserve two bits of fractional precision shifted off the right end. The Sticky bit is unique: it is computed as a logical OR-reduction of all bits shifted off past Round. Once the Sticky bit is set to one, it stays one throughout normalization. When breaking ties in Round-to-Nearest-Even (where Guard is one and both Round and Sticky are zero), the hardware inspects the least significant bit of the mantissa: if the LSB is one (odd), it rounds up to even; if the LSB is zero (even), it truncates.
